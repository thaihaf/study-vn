# Admin surfaces override

Inherits `../MASTER.md`.

- Density: 7/10 — information-dense but grouped.
- Motion: 2/10.
- Variance: 3/10.
- Permanent desktop sidebar is appropriate; on narrow screens it may become horizontal/scrollable navigation or a future sheet menu.
- Dashboard metrics use compact cards; labels are Vietnamese-first and status text should be human-readable rather than raw enum when practical.
- Primary create action sits in page heading; secondary management links are quieter.
- Tables should keep headers/row actions understandable at zoom and mobile. Horizontal scroll is acceptable inside `.table-scroll` only.
- Forms use visible labels and inline helper/error text.
- Destructive actions use danger styling + confirmation and are spatially separated from primary save/publish actions.
- AI job/source status must expose useful failure text without dumping sensitive technical detail to general users.
