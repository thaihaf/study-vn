# Learner dashboard override

Inherits `../MASTER.md`.

- Density: 5/10 — enough information for progress/review, but not an analytics dashboard.
- Motion: 2/10.
- Variance: 3/10.
- Primary hierarchy: continue-learning card first, then due review/weak topics/recent attempts.
- Progress should read as calm evidence of learning; no celebratory confetti, streak urgency or loss-aversion copy.
- Two-column layout is allowed on desktop; mobile MUST collapse to one column without fixed widths.
- Side cards should remain scannable and avoid long tables.
- Empty states must point to a useful next action (`/explore` or `/practice`).
- Percentage/status must include text, not color alone.
